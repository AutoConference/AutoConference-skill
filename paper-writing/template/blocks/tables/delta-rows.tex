% Main table: `delta-rows` (design-axes.md axis 8; P1).
% Rows are arms; columns are the overall metric then one column per
% condition. The baseline family rows come first, then this paper's arm
% (tinted), then a bold green Delta row with explicit + signs (\deltarow).
% No bold cells: the Delta row carries the emphasis. One vertical rule
% separates the overall column from the per-condition columns, as in P1.
% Caption ABOVE. Every cell is filled from a traceable aggregate.
%
% Reporting uncertainty (references/table-grammar.md, "Reporting
% uncertainty" -- read that section before filling this in): every
% per-condition cell carries `mean [lo, hi]`, lo/hi = min/max of that arm's
% own per_split[condition]['values'] in its aggregate -- the same repeated
% runs the mean itself averages, and the same statistic
% scripts/make_paper_data.py's write_opening() already uses for the primary
% arm's figure error band. Bracket, never `mean $\pm$ std`: the range is
% observed, not computed from a symmetric formula, so it is rarely symmetric
% around the mean, and collapsing it to a half-width states a precision the
% data does not have. This grammar's Overall column stays a POINT ESTIMATE,
% never bracketed: its own `std` is the spread ACROSS conditions
% (heterogeneity), not repeated-run noise, and reporting that as if it were
% the mean's confidence interval would be a fabricated-spread defect, the
% same failure mode quality.example.json warns against for instance counts.
% The Delta row also stays a point value: it is a difference (or ratio) of
% two already-uncertain quantities, and propagating an interval through that
% arithmetic is a new statistical claim, not a transcription -- delta/contrast
% columns are already exempt from check_paper_structure.py's numeric checks
% for the same reason. Every real draw of this grammar so far (S03) fit the
% full per-cell treatment at this grammar's default font size; if a future
% instance has enough conditions that \acfit shrinks past legibility, drop a
% condition column before falling back to bracketing only the primary row.
